# Life Dashboard

生活の記録を1画面で回すための個人用 PWA。単一HTMLファイル・外部ライブラリ依存ゼロ・オフライン動作。

**公開URL:** https://rusk-claude.github.io/pld-k7x2m9/

## 1. 何のアプリか

毎日の記録(3行の振り返り・体調・睡眠・勉強・支出・明日の一手)を1〜3分で残し、
週末にその週を見返すためのアプリ。Personal AI System の本体として長期運用・改善していく。

記録するのは **iPhone のホーム画面アイコンから起動したこのアプリのみ**。
他の場所(チャット・メモアプリ等)に同じ記録を分散させない。

## 2. 画面

| 画面 | 内容 |
|---|---|
| ① 今日の記録 | 3行の振り返り・体調・睡眠時間・勉強内容と分数・支出・明日の一手 |
| ② 履歴 | 過去のエントリを日付順に閲覧 |
| ③ リスト | ウィッシュリスト / デバイス不具合ログ(症状・試したこと・状態) |
| ④ 週次レビュー | 「記録した日数 ○/7日」、続いたこと / 止まったこと / 次の一手 |

「記録した日数 ○/7日」がこのプロジェクトの最重要指標(有効利用日数)であり、
アプリ自身がその実績を計測している。別途スプレッドシートでの管理は不要。

## 3. データ

- 保存先は **ブラウザの localStorage**。サーバーもアカウントもない
- キー: `pld_entries` / `pld_wishlist` / `pld_devices` / `pld_weekly`
- **localStorage は端末ごとに独立している。**記録するのは iPhone のみ、Windows は閲覧専用
- 必ず**ホーム画面のアイコンから起動する**(通常の Safari タブよりストレージが保持されやすい)

## 4. バックアップ(エクスポート / インポート)

localStorage はブラウザ都合で消え得るため、週1回のエクスポートを運用に組み込んでいる。

**手順(週1回・日曜のレビュー時)**

1. iPhone でアプリを開き、エクスポートを実行して JSON を書き出す
2. その JSON を OneDrive の指定フォルダへ格納する

**方向のルール**

- エクスポートは常に **iPhone 発**、インポートは **PC のみ**。逆流させない
- インポートは既存データを上書きするため、双方向に流すと片方が消える
- PC → iPhone へ戻すのは、iPhone のデータが消失した緊急時のみ
